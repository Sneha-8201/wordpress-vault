🔍 6. SEO Sticky Note

🧠 What is SEO?

SEO = Search Engine Optimization. It helps search engines understand your website and can help your pages appear in relevant search results.

📌 Important SEO Elements

  • Page title
  • Meta description
  • Clean URL
  • H1
  • H2/H3 headings
  • Relevant keywords/topics
  • Internal links
  • Useful external links
  • Image ALT text
  • XML sitemap
  • Robots.txt
  • Mobile responsiveness
  • Page speed
  • Structured data / Schema

🚀 8. Speed Optimization

⚡ Remember this formula

Images + Cache + CSS + JS + Fonts + Database + Hosting

🖼️ Images

Resize and compress images. Consider WebP or AVIF.

💨 Cache

Use an appropriate caching solution for your hosting stack.

📦 Plugins

Remove plugins you do not need and avoid redundant plugins.

🧹 Database

Keep the database healthy and avoid unnecessary clutter.

🔤 Fonts

Use a sensible number of font files and weights.

🌐 Hosting

Good hosting affects response time, reliability and scalability.

Useful plugins: LiteSpeed Cache, WP Rocket, WP-Optimize, Smush and ShortPixel.

📧 12. WordPress Email

WordPress → SMTP → Email Provider → Recipient

Useful plugins

  • WP Mail SMTP
  • FluentSMTP
  • Post SMTP
Why SMTP? WordPress's default mail delivery can be unreliable depending on the hosting environment. SMTP gives you a more reliable authenticated mail route when configured correctly.

🧠 15. Child Theme

🌱 What is a child theme?

A child theme lets you customize a parent theme while keeping your customizations separate from the parent theme's files.

Important: Avoid directly modifying a parent theme when you need changes that must survive parent-theme updates. Use a child theme or an appropriate customization method.

🔒 19. SSL / HTTPS

SSL/TLS enables secure HTTPS connections.

https://mywebsite.com

instead of:

http://mywebsite.com
Remember: Modern websites should normally use HTTPS, especially when handling logins, forms or ecommerce transactions.
